## 从一个具体的问题开始

想象一个在网格中移动的智能体。它知道自己目前的位置，可以选择向上、向下、向左或向右，但并不知道哪一条路最好。

每走一步，环境给它一个反馈：新的位置，以及这一步得到的回报。智能体需要利用这些经历，逐渐找到更好的行动方式。

这里已经出现了强化学习最基本的几个元素：**状态、动作、奖励，以及选择动作的策略**。

## 奖励不是价值

奖励是一次交互中得到的即时反馈，价值则关心长期结果。一个动作可能立即得到一点好处，却把自己带到一个很难离开的角落；另一个动作眼下看似没有收益，却能通向最终目标。

所以，评价一个动作，不能只看眼前的那一次奖励。常见的做法是将未来奖励按折扣因子 γ 加权求和：越远的奖励，权重通常越小。这里的“价值”是对这个长期回报的期望。

策略回答“现在怎么做”，价值函数帮助回答“这样做，长期来看可能有多好”。

## 用新经历修正旧判断

我们可以先给每个状态和动作一个粗略的价值估计。交互之后，将新的经验与原来的估计进行比较，再做一次小幅修正。

以 Q-learning 的单步更新为例：

```text
target = reward + gamma * max_a Q(next_state, a)
error  = target - Q(state, action)
Q(state, action) += alpha * error
```

其中，`alpha` 决定这次更新的幅度；`gamma` 表示对未来回报的折扣。若下一状态已经是终止状态，后续价值按零处理，目标就只剩当前奖励。

这个过程并不要求我们在一开始就知道完整答案。它从旧估计出发，把一次交互得到的信息纳入判断。

## 探索与利用之间

如果永远选择当前估计最好的动作，可能会一直错过尚未尝试过的好路线；如果永远随机行动，又不能充分利用已经学到的经验。

这就是探索与利用之间的取舍。ε-greedy 是一种直观方法：以较小的概率随机探索，其余时候选择当前价值估计最高的动作。

需要区分的是，“经历了很多步”并不自动意味着学到了好的策略。状态是否被充分访问、更新是否正确、终止状态是否处理得当，都会影响结果。

## 学习时值得追问什么

面对一次实验，可以先检查几个具体问题：

1. 状态里是否包含了决策所需要的信息？
2. 奖励是否和真正想实现的目标一致？
3. 更新目标使用的是实际的下一动作，还是下一状态下估计最优的动作？
4. 展示的是训练期间的探索行为，还是训练之后固定策略的表现？

这些问题往往比一张最终曲线更能帮助我们理解算法。先弄清每次反馈如何改变判断，再看复杂环境，许多公式就会有可以落脚的直觉。
